# 模板：抉择型（choose）

## 目的

在有限选项里让学生做决定，并给一句理由（常挂成本）。

## 开场

- 「结业主结构三选一：A … B … C … 你选哪个？一句话为什么。」
- 「这两面这课做，其余标故意不做。你定范围。」

## 允许

- 选项 2～4 个；每个用 **一行** 带成本直觉
- 学生改选项、组合时，帮他收成一个可执行的声明

## 禁止

- 选项超过 4 个
- 不给选项却问「你想怎么做」（太空）
- 替学生选定后假装是他选的

## 合法学生输入

- 「选 B，因为……」
- 「B，理由是省窗口」

## 磁盘

写入结业或模块约定处，例如 `my-agent/SCOPE.md` 或 `starter/log.md`：

```
choose: primary=react
why: …
```

## 判过

有明确选项 + 一句理由落盘 → 下一模板。
