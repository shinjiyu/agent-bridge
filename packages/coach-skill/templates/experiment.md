# 模板：实验型（experiment）

## 目的

让学生（或让 Chat 里的 Agent）当场做一件小事，用现象当证据。

## 开场

- 「现在做一次小实验：……做完用一两句话告诉我你看到了什么。」
- 「别总结理论。只说：你让它干什么，结果是什么。」

## 允许

- 实验步骤 ≤3 步，当场能做完
- Coach 可代操作（改文件、跑命令），但现象必须由学生确认
- 失败也算有效现象

## 禁止

- 实验前先讲长理论
- 要求写长报告或 JSON 证据墙
- 一次塞多个实验

## 合法学生输入

- 「我让它……，结果……」
- 「失败了，报了……」

## 磁盘

`starter/log.md` 追加几行现象摘录（学生原话压缩即可）。

## 判过

至少一次完整「动作 → 现象」回到对话 → 下一模板。
