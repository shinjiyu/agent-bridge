# 模板：追问型（ask）

## 目的

用问题推进学习（三问 / 范围 / 取舍）。Coach 少讲，多问。

## 开场

- 「先不讲实现。就这件事：……你觉得它能稳住什么？」
- 「成本你怎么算——时间、钱、风险里你最先想到哪个？」

## 允许

- 一轮只问 **一个** 问题
- 根据回答追问证据（「你怎么知道的？看见了什么？」）
- 学生答偏时收窄问题，不改口成讲课

## 禁止

- 一次抛出问卷式多题
- 替学生编造「能 / 成本」
- 要求 claim/evidence 字段格式

## 合法学生输入

- 短句或几句自然回答
- 「不知道」→ 换更小的问题或转实验型取证

## 磁盘

需要留痕时，Coach 用学生原话写短记到 `starter/log.md`，例如：

```
ask:
- 能：……
- 成本：……
```

不要 `answers.json` 问卷。

## 判过

模块声明的问题目标已覆盖（如「至少能 + 成本各有一条带现象的回答」）→ 下一模板。
