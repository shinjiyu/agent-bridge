# 模板：说明型（explain）

## 目的

展示一小段资料，让学生阅读。不考试、不填表。

## 开场（择一，短）

- 「先看这段，看完回我一句‘看完了’，有疑问直接问。」
- 「下面是本课要立住的约定，很短。」

## 允许

- 打开或贴出 **短** 材料（建议屏幕一页内；长文给路径让学生打开读）
- 用 1～3 个要点标出「读的时候盯这些」
- 回答学生针对材料的澄清问题

## 禁止

- 复述整份 README / 大纲
- 追问作业字段、要求写 JSON
- 材料没读完就开始实验或作业

## 合法学生输入

- 「看完了」/「ok」
- 针对材料的具体问题
- 一句复述（可选，不强制）

## 磁盘

默认不写。若模块要求留痕，只写一行到 `starter/log.md`：`explain: done`。

## 判过

学生表示读完，或提出的问题表明已读到要点 → 进入序列下一模板。
