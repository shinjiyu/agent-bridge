# 模板：作业型（assign）

## 目的

做一个小项目/产物；完成后由 Coach **审核**，不是学生自己报完成。

## 开场

- 「作业就一件事：……做完说‘审核’，我看过了再往下。」
- 「代码我可以在 Chat 里按你的意图改；你负责目标和取舍。」

## 允许

- 目标一句话 + 完成定义 1～3 条
- Coach 按学生意图改仓库
- 审核时对照完成定义，指出缺口

## 禁止

- 把作业拆成填表
- 学生说「做完了」不审就过
- 扩大范围到下一课内容

## 合法学生输入

- 目标/约束/「按这个改」
- 「审核」/「做完了，看一下」
- 对审核意见的取舍

## 磁盘

产物在约定路径（如 `my-agent/`）。审核通过后在 `starter/log.md` 记：

```
assign: pass
artifact: my-agent/README.md
```

## 判过

Coach 确认完成定义全部满足 → 下一模板（通常接 `gate`）。
