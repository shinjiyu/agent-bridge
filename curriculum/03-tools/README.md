# Module 3 — 工具入门

**模板**：说明 → 实验 → 追问 → 验收门  
**对应**：K1

## 说明型

工具：模型提出调用 → **结果写回前缀** → 再逐 token 生成。

## 实验型

当场走一次「假工具」或真工具：看观察如何进下一轮上下文。一两句现象即可。

## 追问型

工具结果若不写回前缀，模型还能不能基于结果继续？成本多在哪？

## 验收门

`grade 3`：log 有 experiment + 提到写回前缀/上下文。
