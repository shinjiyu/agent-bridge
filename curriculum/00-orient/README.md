# Module 0 — 学法：能 / 不能 / 成本

**时长**：约 2 小时  
**目标**：先学会怎么学。后面每一课都用同一把尺子。

学一个新东西，第一步不是背定义，而是亲手摸清三件事：

1. **能做什么**：你亲眼见它做成的
2. **不能做什么**：你亲手让它失败的
3. **成本**：做成这件事要付的时间、钱、注意力和风险

没有证据的判断不算数。「我觉得它很强」不是能力；「我让它做了 X，结果是 Y」才是。

## 这一课摸什么

摸你正在用的 **Cursor Agent**（这个编程助手本身）。  
不要写综述，不要抄文档首页。每条都来自你刚做的一次尝试。

## 你要交什么

填 `starter/capability-card.json`：

- `can`：至少 2 条。它做成了什么。
- `cannot`：至少 2 条。你要求它做、但它没做成或不该做的。
- `costs`：至少 3 条，且种类里必须同时出现 `time`、`money`、`risk`。
  - `time`：你或它花了多久
  - `money`：token、订阅、返工工时（用钱或等价值说清）
  - `risk`：做错了会怎样（改错文件、泄密、幻觉当事实）

每条都要有 `claim`（一句话）和 `evidence`（你做了什么、看到了什么，至少 20 字）。

`subject` 固定写 `Cursor Agent`。

## 验收

`agent-bridge grade 0`

通过只代表卡片结构完整、三条成本种类齐全、证据不是空话。对不对，由你自己在下一课继续用这把尺子验。
