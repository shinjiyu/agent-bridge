# Agent Bridge

面向个人的「程序员 → AI Agent 工程师」转型学习系统。

- 在 **Cursor / Claude Code 的 Chat** 里学与练（可读文件；不要求手写课程代码）
- Coach 在对话里开课、提问、改仓库、代跑 `init` / 进度 / `grade`
- **结业物**：一套可跑、可冒烟的 Agent 系统（Harness）
- **知识地图**：[agent-harness-articles](https://github.com/shinjiyu/agent-harness-articles)；**学法**见本课主张

**主张与模块顺序**见 [OUTLINE.md](./OUTLINE.md)。  
快速开始见 [GETTING_STARTED.md](./GETTING_STARTED.md)。

学习主路径：在 Chat 对 Coach 说「继续下一课」→ 对话里回答 → Coach 写 `starter/` 与 `my-agent/` → 「帮我评分」。
